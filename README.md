# Udemy 学習リフレクション

MacBook（Apple Silicon）で使えるローカルWebアプリ。Python標準ライブラリとSQLiteのみで動作します。Udemyへのログイン、API、外部通信、追加パッケージは不要です。

## 起動

1. このフォルダを好きな場所に置きます。
2. ターミナルでこのフォルダに移動して実行します。

```sh
python3 app.py
```

3. ブラウザで http://127.0.0.1:8765 を開きます。
4. 終了はターミナルで `Control + C`。

`start.command` をダブルクリックしても起動できます。macOSが実行をブロックする場合は、上記のターミナル手順を使ってください。ブラウザは手動で開きます。

Python 3.9以上が必要です。`python3 --version` で確認できます。入っていない場合は https://www.python.org/downloads/macos/ のmacOS用universal2インストーラ（Apple Silicon対応）でPython 3をインストールしてください。

ポートが使用中の場合：

```sh
python3 app.py --port 8766
```

その場合は http://127.0.0.1:8766 を開きます。

## 使い方

1. 講座名を登録し、講座を選びます。
2. 単元・レクチャーを学習順に追加します。必要なら「第1章 / 03 引数」のように章名と番号を含めます。
3. 視聴後に単元のチェックを入れ、単元名をクリックします。
4. 理解したこと、不明点、満足度、評価理由、理解度、日時、自由記述を記録します。評価理由と日時は必須です。満足度と理解度は1〜5で、別々に評価します。
5. 復習したら同じ単元に再度記録します。履歴が追加されます。記録日時が最新のものを現在の理解度として表示します（同日時なら後に保存した記録）。
6. 講座の進捗バー、記録済み単元数、見直し候補を確認します。単元一覧で未視聴・弱点・視聴済み未記入を絞り込めます。

理解度の目安：1 ほぼ不明 / 2 一部理解 / 3 概要を理解 / 4 説明できる / 5 応用できる。
見直し候補は最新記録の理解度が1〜2、または不明点が記入されている単元です。不明点が解消したら、次の記録では不明点を空にしてください。過去の記録は残ります。

入力途中の内容は自動保存されません。「振り返りを保存」を押してください。視聴チェックは即時保存されます。講座・単元は登録順です。編集・削除・並べ替え・インポート・Udemy自動取得は現在の範囲に含めていません。

## データとバックアップ

データはこのフォルダの `data/reflection.sqlite3` に保存されます。終了しても残ります。サーバー停止後に `data` フォルダ全体をコピーするとバックアップできます。復元は停止状態でバックアップの同ファイルに置き換えます。コードを移動する場合は `data` も一緒に移動してください。

画面上部のJSON保存は全講座・単元・全履歴を出力します。CSVは1振り返りにつき1行、未記録単元も1行出力します。単元がない講座も含めて保存するならJSONを使ってください。CSVはExcel等で読みやすいUTF-8 BOM付きです。数式として扱われる可能性のある文字列には先頭に `'` を付けます。原文の完全保存にはJSONを使ってください。

日時はタイムゾーン付きで保存し、表示と入力はブラウザのローカル時刻を使います。理解度の集計は自己評価に基づきます。

## ローカル運用

127.0.0.1のみに接続を受け付けます。同じMacで使うアプリで、インターネット公開や複数人利用を想定していません。認証はありません。フォルダにアクセスできるMacの利用者はデータを読めます。

## ファイル

- `app.py` — HTTPサーバー、SQLite、エクスポート
- `static/` — 日本語画面
- `start.command` — Mac用ランチャー
- `data/` — 初回起動時に作成

追加ライブラリなしで動くため `pip install` は不要です。

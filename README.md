# MetaWatch（メタウォッチ）

> 「観た」を「学んだ」に変える。
>
> 動画学習の理解と振り返りを記録するツール。

MacBook（Apple Silicon）で使えるローカルWebアプリ。Python標準ライブラリとSQLiteのみで動作します。通常の手動記録にログインや外部通信は不要です。任意の公開カリキュラム取得を使う場合に限り、Udemyの公開ページへ匿名HTTPS接続します（Udemy APIや追加パッケージは使いません）。

## 起動

1. このフォルダを好きな場所に置きます。
2. ターミナルでこのフォルダに移動して実行します。

```sh
python3 app.py
```

3. ブラウザで http://127.0.0.1:8765 を開きます。
4. 終了はターミナルで `Control + C`。

`start.command` をダブルクリックしても起動できます。macOSが実行をブロックする場合は、上記のターミナル手順を使ってください。ブラウザは手動で開きます。

Python 3.9以上が必要です。`python3 --version` で確認できます。入っていない場合は https://www.python.org/downloads/macos/ のmacOS用universal2インストーラ（Apple Silicon対応）でPython 3をインストールしてください。

ポートが使用中の場合：

```sh
python3 app.py --port 8766
```

その場合は http://127.0.0.1:8766 を開きます。

## 使い方

画面上部のナビゲーションから「メインページ」「学習計画」「講座の学習記録」「AIチャット」を切り替えます。メインページには直近4週間の活動履歴カレンダーを7列×4行で表示します。記録済みの日は深緑、未記録の日は淡黄緑で、日付を選ぶとその日の振り返りを確認できます。カレンダーの下にはAI学習リフレクションを表示します。

1. 「講座の学習記録」ページでは、手入力の講座名登録とUdemy公開カリキュラムの取り込みを別の操作として利用できます。同じ講座名（全角/半角、大文字/小文字、余分な空白を正規化したもの）は重複登録できません。URL取り込みでは専用欄にHTTPSの `udemy.com/course/...` を入力し、プレビューを確認してから登録します。
2. 「学習計画」ページで対象日と講座を選び、その講座の単元から複数をチェックして一度に計画へ追加できます。講座を選ぶ前に全講座の単元一覧は表示されません。視聴済みの単元も「視聴済み」と表示したうえで復習用に選べます。当日の計画に追加済みの単元は重複して選べません。未登録の場合は講座名と単元名を入力して計画に追加できます。新しい講座と単元も登録され、講座の学習記録ページから利用できます。
3. 学習後、「1日の学習を終了」から実際の学習時間、自己評価、改善点、明日の計画を記録します。計画達成率は計画単元数を母数、当日（日本時間）に振り返りを1件以上記録した計画単元数を分子として自動計算します。計画がない日は「計画なし/算出対象なし」と表示します。従来の計画完了booleanは履歴・JSON/APIに保持し、新しい記録では達成率が100%の場合だけtrueとして保存します。日次記録は履歴として残り、記録した日は直近4週間の28枠カレンダーに緑色で表示されます。今日の計画がない場合は画面上部に登録を促す案内が表示されます。
4. 「講座の学習記録」ページでは、「講座全体の評価」で講座全体の理解度と講師とのマッチ度をそれぞれ1〜5で評価し、個別に理由を記入します。単元ごとの振り返りとは独立しており、再評価は履歴に追加されます。
5. 単元・レクチャーは手入力で追加できます。Udemy URL取り込みでは、取得した公開件数との照合が成功した場合に動画タイトルのみをプレビューします。セクション名・動画時間は単元に登録・表示しません。「この講座と単元を登録」を明示的に押すまでは講座や単元は作成されません。登録時にURLごとに講座を1件だけ作成し、同じURLの講座が既にある場合は再利用します。既存の単元や視聴状態は上書きせず、既存タイトルと重複しない動画タイトルを追加します。視聴後にチェックを入れ、単元名をクリックします。
6. 理解したこと、不明点、満足度、評価理由、理解度、日時、自由記述（追加で自身で調べて理解したこと）を記録します。評価理由と日時は必須です。満足度と理解度は1〜5で、別々に評価します。
7. 復習したら同じ単元に再度記録します。履歴が追加されます。記録日時が最新のものを現在の理解度として表示します（同日時なら後に保存した記録）。
8. 講座の進捗バー、記録済み単元数、見直し候補を確認します。単元一覧で未視聴・弱点・視聴済み未記入を絞り込めます。
9. 講座一覧の「削除」から講座・単元・単元の振り返り・講座評価・学習計画・関連する計画日の振り返りを確認できます。削除を実行するには、表示された全対象への同意が必要です。1つでも未選択、または最終確認でキャンセルした場合は、講座を含め何も削除しません。実行すると対象一式を完全削除し、アーカイブは作成しません。プレビューは30分間有効で、表示後に関連データが変わった場合は削除を中止し、最新の内容を再確認します。

### AIチャット

「AIチャット」ページは、学習計画・日次振り返り・AI学習リフレクションとは独立した会話ページです。初期状態は自然体の話し方です。画面左の設定から「丁寧」「自然体」「フレンドリー」を選べます。変更はSQLiteに保存され、次の送信から応答スタイルへ反映されます。質問頻度など、話し方以外の人格設定はありません。ページを開いただけでは挨拶やOpenAI API要求は発生しません。

チャットを始める前に「New chat」で学習日ごとのセッションを作ります。同じ日に複数のセッションを作成でき、過去の学習日を選ぶとその日の保存済み履歴を閲覧できます。送信前に、本文と回答に必要な直近の会話履歴がOpenAIへ送信される旨を確認し、チャット専用の同意操作を行ってください。この同意はAI学習リフレクションの同意とは別に保存されます。チャット内容は同意後、OpenAI APIを通じて外部へ送信されます。APIキーは既存のAI学習リフレクションと同じ安全なローカル設定ファイルを優先して読み、なければ `OPENAI_API_KEY` 環境変数を使います。キーはブラウザー、チャット履歴、エクスポートへ返しません。モデルは既定 `gpt-4o-mini`、`OPENAI_MODEL` が設定されている場合はそのモデルを使用します。

「利用上限（管理用設定）」はAIチャット専用で、初期値は日本時間の1日20リクエストです。上限は1〜500回で設定でき、AI学習リフレクションの自動分析枠とは独立しています。送信リクエストはSQLite上で原子的に枠を予約してからOpenAIを呼びます。同一セッションの同時送信は1つに制限し、複数タブ・同時処理・アプリ再起動をまたいでも設定上限を超えて予約しません。OpenAI要求を開始した後のAPIエラーやタイムアウトでも枠は消費済みとして記録され、失敗したユーザー発言もローカル履歴に残ります。再送信は新しいリクエストとして追加で枠を1回消費します。OpenAIを呼ぶ前の同意なし、キーなし、日次上限到達、同一セッション処理中の要求はAPIへ送信されず、利用枠も増えません。日々のリクエスト数と入出力token数を画面に表示しますが、料金はモデルや契約条件で異なるため固定価格の見積もりは表示しません。

### AIチャット履歴の保存とエクスポート

チャットセッション、発言、話し方、モデル、token数、利用上限、日別の利用集計、同意日時は、既存学習データと分離したSQLiteテーブルに保存します。発言日時はUTCのタイムスタンプ、学習日はAsia/Tokyoの日付として別々に保持します。daily_reflectionsのIDには結び付けず、振り返りがない日もチャットできます。API失敗時はユーザー発言を保存してエラーと再送信手段を表示します。画面へ戻る/再起動後も保存済み会話を表示できます。

AIチャットページの「チャット履歴をCSV保存」は全チャット発言を1行ずつ、指定列とUTF-8 BOM付きで出力します。数式として解釈される可能性がある文字列には先頭に `'` を付けます。既存の全データJSON (`/api/export.json`) と「計画・日次振り返りをJSON保存」(`/api/export/planning.json`) にもチャットセッション、発言、設定、利用集計、同意情報を含めます。これらのエクスポートにAPIキーは含めません。AIチャットの詳しいデータフロー、利用枠予約、失敗時の扱いは[AI学習リフレクション 設計・解析書](docs/ai-learning-reflection-design.md)内のAIチャット節を参照してください。

理解度の目安：1 ほぼ不明 / 2 一部理解 / 3 概要を理解 / 4 説明できる / 5 応用できる。
見直し候補は最新記録の理解度が1〜2、または不明点が記入されている単元です。不明点が解消したら、次の記録では不明点を空にしてください。過去の記録は残ります。

入力途中の内容は自動保存されません。「振り返りを保存」を押してください。視聴チェックは即時保存されます。手入力した単元と取り込んだレクチャーは講座内の登録順を保ちます。講座の削除は関連記録を確認したうえで、講座と関連記録一式の削除に同意した場合だけ実行できます。講座や単元の編集・並べ替え・ファイルインポートは現在の範囲に含めていません。

### AI学習リフレクション

初回は、日次振り返りと当日の学習計画の内容がOpenAIへ送信されることへの同意が必要です。送信対象は記録日時、自己評価、学習時間、計画達成、改善点、明日の計画、および当日の講座名・単元名です。AI学習リフレクション欄のパスワード入力からAPIキーを保存できます。キーはアプリ専用のローカル設定ファイル `~/Library/Application Support/MetaWatch/openai-key.json` に保存し、設定フォルダーはアクセス権0700、ファイルは0600に制限します。書き込みは一時ファイルを使ってアトミックに置き換えます。

以前から利用しているサーバー環境変数 `OPENAI_API_KEY` も引き続き使えます。アプリ画面から保存したキーを優先し、ローカル設定ファイルにキーがない場合だけ環境変数へフォールバックします。画面にはキー値を返さず、保存元だけを表示します。ローカル保存キーを削除した場合、環境変数が設定されていればそちらへ切り替わります。環境変数だけで管理しているキーはアプリ画面から削除できません。既定モデルは `gpt-4o-mini` で、必要な場合は `OPENAI_MODEL` で変更できます。

APIキーの保存・削除・環境変数との優先順位、同意・日次実行制限・保存データ・エラー時の挙動など、実装に基づく詳しい説明は[AI学習リフレクション 設計・解析書](docs/ai-learning-reflection-design.md)を参照してください。設定ファイルは暗号化されないため、同じOSユーザー権限で実行されるプロセスからは読み取れます。端末アカウントとバックアップを保護してください。

同意済みでAPIキーと分析対象記録がある日の初回アクセス時に、Asia/Tokyoの日付ごとに自動分析を最大1回実行します。対象は当日を含む直近14日間の日次振り返りと当日の計画で、記録がある日だけを送信します。昨日の記録がない場合はその旨を区別して表示し、空白日は否定的に評価しません。自動分析結果・対象record ID・入力ハッシュ・モデル・prompt versionはSQLiteに保持します。同日の再訪では保存結果を表示し、記録や計画が変わった場合は古い結果として示しますが、自動再分析はしません。手動再分析はOpenAIへの追加リクエストとなり、追加料金が発生し得るため、実行前に確認します。API失敗後に自動再試行はしません。

分析内容は「昨日の振り返り」「過去の記録から見えること」「今日の学習に向けて」の3項目です。記録にない成果や能力を推測しないよう指示しますが、AIの出力は参考情報であり正確性を保証しません。APIキー未設定、同意なし、分析対象0件の場合はAPIを呼び出しません。外部送信に同意しない場合、この機能は未生成のまま利用できます。

### Udemy公開カリキュラム取得について

取得はUdemyの公開講座ページに対する匿名HTTPS GETのみで、ログイン、Cookie、Udemy API、JavaScript実行は使用しません。接続先をUdemyの正確なホスト名に限定し、DNS応答の公開IP確認後にそのIPへ接続を固定します。リダイレクトは追跡せず、タイムアウトと応答サイズ上限を設け、取得リクエストは再試行しません。カリキュラムがない、公開件数が確認できない、または件数が合わない場合は登録処理を停止します。

講座URLは前後の空白を除き、クエリとフラグメントを取り除いた正規URLとして保存・取得します。ページ内の公開HTML構造に依存するため、取得可否や内容はUdemy側の変更、公開状態、地域や実行環境などで変わり、結果の正確性・継続性は保証されません。検証報告では `learn-basics-of-linux` の公開HTMLから10セクション・100レクチャーが取得され件数照合できましたが、他の講座や環境での動作を保証するものではありません。取得に失敗した場合は画面にエラーと手動入力の案内を表示します。JSON/CSV保存または単元の手動登録を利用してください。日次振り返りの学習時間は実際にかかった学習時間を記録するもので、Udemy動画時間とは別です。

取得・解析を分けて確認する場合は、アプリのフォルダーで次を実行します。公開HTML本体を `/tmp/metawatch-udemy-course.html` に保存し、続けて保存済みHTMLの解析件数を表示します。

```sh
python3 - <<'PY'
from pathlib import Path
import app

url = 'https://www.udemy.com/course/learn-basics-of-linux/'
markup = app.fetch_udemy_course_html(url)
html_path = Path('/tmp/metawatch-udemy-course.html')
html_path.write_text(markup, encoding='utf-8')
print('取得文字数:', len(markup), '保存先:', html_path)
saved_html = html_path.read_text(encoding='utf-8')
try:
    result = app.parse_course_curriculum(saved_html)
    print('講座名:', result['course_name'])
    print('公開レクチャー数:', result['expected_lectures'])
    print('取得タイトル数:', len(result['lectures']))
except app.CurriculumParseError as error:
    print('解析エラー:', error)
PY
```

HTMLは公開講座ページの全体を取得しますが、登録対象として解析するのはカリキュラムの公開件数と動画タイトルです。取得HTMLにはページ全体の公開情報が含まれるため、共有・コミットせずローカルで確認してください。

## データとバックアップ

データはこのフォルダの `data/reflection.sqlite3` に保存されます。終了しても残ります。サーバー停止後に `data` フォルダ全体をコピーするとバックアップできます。復元は停止状態でバックアップの同ファイルに置き換えます。コードを移動する場合は `data` も一緒に移動してください。

「学習計画」ページから計画・日次振り返りのJSON、「講座の学習記録」ページから講座・単元・評価・振り返りのJSONと単元振り返りCSV、「AIチャット」ページからチャットCSVをダウンロードできます。JSON/CSVには既存DBで保持されているセクション・順序・時間の値も互換性のため含まれますが、新しいUdemy取り込みでは動画タイトルだけを単元として保存します。計画のJSONには講座・単元一覧も含まれ、計画IDを名前と対応付けられます。計画・日次振り返りJSONと全データJSONにはチャットデータも含みます。全データJSON（`/api/export.json`）は過去バージョンで作成されたアーカイブがあればエクスポートに含めます。CSVは1振り返りまたはチャットメッセージにつき1行で、数式として扱われる可能性のある文字列には先頭に `'` を付けます。CSVはExcel等で読みやすいUTF-8 BOM付きです。原文の完全保存にはJSONを使ってください。

講座評価・日々の計画・1日の振り返り・セクション情報・AI同意・日別呼び出し上限・AI分析結果・AIチャットは追加テーブルに、講座URL・正規化した講座名キーと単元のセクション・順序・時間は既存テーブルへの列追加で保存します。既存DBでも不足テーブル・列だけを追加するため、既存の講座・単元・振り返り・視聴状態はそのまま維持されます。移行前から存在する同名講座も削除・統合せず保持し、新規登録時に同名を検出して案内します。

日時はタイムゾーン付きで保存し、表示と入力はブラウザのローカル時刻を使います。理解度の集計は自己評価に基づきます。

## ローカル運用

アプリ自身は127.0.0.1のみに接続を受け付けます。同じMacで使うアプリで、インターネット公開や複数人利用を想定していません。認証はありません。フォルダにアクセスできるMacの利用者はデータを読めます。公開カリキュラム取得をユーザーが明示的に実行した場合だけUdemyへHTTPS接続します。AIリフレクションは同機能の同意、チャットはチャット専用同意とAPIキー設定後にのみOpenAI APIへ送信します。チャット同意は会話履歴を保存する前に取得します。

## テスト

既存機能とAIチャットのテストはPython標準ライブラリで実行できます。

```sh
python3 -m unittest -q
```

テストではOpenAI通信をモックし、実APIキーやインターネット上のOpenAI接続を必要としません。

## ファイル

- `app.py` — HTTPサーバー、SQLite、エクスポート
- `static/` — 日本語画面（メイン、学習計画、講座の学習記録、AIチャット）と画像
- `test_app.py`, `test_ai_chat.py` — 既存機能とAIチャットのテスト
- `tests/fixtures/` — 公開カリキュラムHTMLの解析テスト用fixture
- `start.command` — Mac用ランチャー
- `data/` — 初回起動時に作成

追加ライブラリなしで動くため `pip install` は不要です。
